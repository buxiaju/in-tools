# 文件搜索

按文件名关键词找文件。只用 Python 标准库，不读文件内容，所以不会因为大文件卡住。

## 怎么用

在对话里直接说需求即可，例如「在 D 盘找一下名字带 report 的文件」。AI 会调用 `search:files`。

也可以精确地给参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `keyword` | 是 | 文件名里要包含的关键词，不区分大小写 |
| `directory` | 否 | 搜索根目录，默认用户主目录 |
| `max_results` | 否 | 最多返回几条，默认 50，上限 500 |

返回匹配到的文件路径列表。

## 权限

声明了 `file:read`（低危），装上就生效，不会额外弹窗。它只列目录、比对文件名，不打开文件。

## 需要知道的限制

- **匹配的是文件名，不是内容。** 想搜内容里的关键词，这个插件做不到。
- **递归整棵目录树。** 根目录选得太大（比如整个 C 盘）会慢，建议尽量指定到具体目录。
- 结果数量到了 `max_results` 就停，不保证是「最相关」的那几个——先遍历到的先返回。

## 它没有的东西

这个插件**没有快捷键、没有界面**，只有一个工具。这两项都是可选的：不声明，插件卡片上就不会出现对应按钮。
