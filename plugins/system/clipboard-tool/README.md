# 剪贴板工具

读取和写入系统剪贴板的文本内容，并提供剪贴板历史记录。

## 快捷键

按 `Ctrl+Shift+V` 打开剪贴板历史面板。

### 历史面板功能

- 显示最近 50 条复制过的文本记录（按时间倒序）
- 支持搜索过滤（输入关键词即时筛选）
- 点击任意条目 → 自动复制到剪贴板 → 600ms 后自动关闭面板
- 按 ESC 关闭面板

### 工作原理

宿主后台每 500ms 轮询系统剪贴板变化，内容变化时自动追加到历史记录。历史持久化存储在 `~/.intools/clipboard-history.json`，重启后保留。

## 工具列表

| 工具                      | 说明           |
| ----------------------- | ------------ |
| `clipboard:read_text`   | 读取剪贴板中的纯文本   |
| `clipboard:write_text`  | 将文本写入剪贴板（覆盖） |
| `clipboard:append_text` | 追加文本到剪贴板现有内容 |
| `clipboard:clear`       | 清空剪贴板        |
| `clipboard:has_text`    | 检测剪贴板是否包含文本  |

## 用法示例

在对话中可以这样说：

- 「读取剪贴板内容」

- 「把这段文字复制到剪贴板：……」

- 「把刚才的结果追加到剪贴板」

- 「清空剪贴板」

- 「剪贴板里有文字吗」

## 返回格式

### read\_text

```json
{
  "text": "剪贴板中的内容",
  "length": 10,
  "has_text": true
}
```

### write\_text / append\_text

```json
{
  "ok": true,
  "length": 10
}
```

## 权限说明

- `clipboard:read`：读取剪贴板内容

- `clipboard:write`：写入剪贴板

## 限制

- 仅支持 Windows

- 目前只处理纯文本格式（CF\_UNICODETEXT），不支持图片、文件列表等格式

- 如果剪贴板被其他程序占用，会自动重试最多 10 次
