# 插件生成器

在 AI 对话中一句话生成完整插件。

## 使用方式

在 AI 对话中说：

- "帮我做一个天气查询插件"
- "创建一个翻译工具插件，支持中英互译"
- "做一个文件加密插件，用 Node.js"

AI 会自动调用 `plugin:generate` 生成完整项目：

1. `manifest.toml` — 插件元数据、工具声明、权限、UI 配置
2. `main.py` / `main.js` / `main.go` — 可运行的入口文件骨架
3. `README.md` — 使用说明

生成后在插件页点击「刷新」即可看到。

## 工具

| 工具 | 说明 |
|------|------|
| `plugin:generate` | 生成完整插件项目 |
| `plugin:list-templates` | 列出可用语言模板 |

## 工作原理

1. 用户描述需求 → AI 理解意图
2. AI 调用 `plugin:generate`，传入结构化参数（名称、描述、工具列表、权限）
3. 插件生成器创建完整项目文件
4. 用户在插件页刷新即可使用

生成的代码包含完整的协议实现和 TODO 注释，开发者只需填充业务逻辑。
