# 文件操作

文件系统的基本操作：读取、写入、列目录、创建目录、删除、复制、移动、获取信息。

## 工具

| 工具 | 说明 |
|------|------|
| `file:read` | 读取文本文件内容 |
| `file:write` | 写入文本文件（覆盖或追加） |
| `file:list` | 列出目录内容 |
| `file:mkdir` | 创建目录（含父目录） |
| `file:delete` | 删除文件或目录 |
| `file:copy` | 复制文件或目录 |
| `file:move` | 移动/重命名文件或目录 |
| `file:info` | 获取文件或目录的详细信息 |
