# 屏幕取色器

获取鼠标当前位置或指定坐标的屏幕像素颜色，返回 HEX / RGB / HSL 格式。

## 用法

### 快捷键取色（推荐）

1. 将鼠标移到想要取色的屏幕位置上
2. 按下 `Ctrl+Alt+C`
3. 颜色的 HEX 值会自动复制到剪贴板，同时返回完整颜色信息

### 在对话中使用

对 AI 说「取一下当前鼠标位置的颜色」即可。也可以指定坐标：

「获取屏幕 (100, 200) 处的颜色」

## 返回格式

```json
{
  "hex": "#FF5733",
  "rgb": {"r": 255, "g": 87, "b": 51},
  "rgb_string": "rgb(255, 87, 51)",
  "hsl": {"h": 11, "s": 100, "l": 60},
  "hsl_string": "hsl(11, 100%, 60%)",
  "position": {"x": 1920, "y": 1080},
  "copied_to_clipboard": true
}
```

## 权限说明

- `screen:capture`：读取屏幕像素颜色
- `clipboard:write`：将 HEX 值复制到剪贴板

## 限制

- 仅支持 Windows（使用 Win32 API）
- 取的是主屏幕的像素，多显示器场景下坐标为全局虚拟屏幕坐标
- 快捷键默认 `Ctrl+Alt+C`，可在插件卡片的「快捷键」里修改
