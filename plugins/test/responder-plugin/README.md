# responder-plugin

反向 RPC 集成测试的响应方插件。声明了 `screen:capture` 权限，用于验证宿主的权限拦截机制。

## 工具

| 工具 | 说明 |
| --- | --- |
| `responder:echo` | 原样返回传入的 `text`，功能与 `hello:echo` 相同 |

## 用途

本插件不提供用户功能，仅供集成测试使用。核心验证点：

- 声明中危权限（`screen:capture`）的插件在首次调用时会触发权限弹窗
- 权限被拒绝后，后续调用同样被拦截
- 权限授予后，工具正常返回结果

## 权限

- `screen:capture`（中危）——故意声明此权限以触发权限拦截测试
