# 系统信息插件

查看本机 CPU、内存、磁盘、网络接口、环境变量等系统信息。

## 语言

本插件使用 **Node.js** 编写，演示「任何语言皆可做插件」。

依赖：仅 Node.js 标准库（`os` / `fs` / `child_process`），无第三方包。

## 工具

| 工具 | 说明 |
|------|------|
| `system:info` | 操作系统、CPU、内存概览 |
| `system:cpu` | 各核心型号、频率、实时使用率 |
| `system:network` | 网络接口及 IP 地址 |
| `system:disk` | 磁盘容量与使用率（Windows） |
| `system:env` | 环境变量，支持按前缀过滤 |
