# Hello 示范插件

最小可运行插件，用来验证「宿主 ↔ 插件」这条链路通不通。自己写插件时可以拿它当模板。

## 它能做什么

- `hello:echo`：原样返回传入的 `text`。
- `hello:crash`：立刻以非零码退出，用来看宿主怎么处理插件崩溃。

## 怎么试

在对话页输入「用 hello:echo 回显 abc」，正常应当看到 `abc` 原样返回。

想看崩溃处理就调 `hello:crash`：这次调用会失败，插件状态转为「错误」，随后按 `on-failure` 策略重启。这是预期行为，不是 bug。

## 它没有的东西

这个插件**没有快捷键、没有界面、没有可配置项**——三者都是可选的。所以插件卡片上不会出现「快捷键」按钮，「设置」里也是空的。这正好说明：只声明工具的插件同样是完整插件。

## 值得抄的两处细节

- `manifest.toml` 里 `args = ["-u", "main.py"]` 的 `-u` 不能省。它关掉 Python 的输出缓冲；缺了它，响应会积在缓冲区里，宿主端表现为所有请求超时。
- `permissions = []` 表示不申请任何权限，因此运行时不会弹授权窗。按需申请，别多要。

完整的开发说明见宿主仓库的 `docs/plugin-development.md`。
