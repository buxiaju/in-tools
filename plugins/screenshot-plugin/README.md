# 屏幕截图

截取屏幕画面，存成 PNG 并返回文件路径。

## 两种用法

- **按快捷键**：默认 `Ctrl+Shift+S`。按下后屏幕变暗，拖出一个矩形即完成截图；按 `Esc` 放弃。

- **在对话里说**：例如「帮我截个图」，AI 会调用 `screenshot:capture` 工具截全屏。

快捷键可以改：插件卡片上点「快捷键」，按下你想要的组合键，保存后立即生效，不用重启。

## 保存位置

默认存到 `~/Pictures`，文件名形如 `screenshot-20260904-153012.png`。

想换目录就在插件卡片上点「设置」，改 `截图保存目录` 这一项。目录不存在时会自动创建。

## 权限

需要 `screen:capture` 权限。首次使用时宿主会弹窗询问，选「始终允许」之后不再打扰。

## 工具参数

`screenshot:capture` 接受两个可选参数：

```json
{
  "output_dir": "D:/shots",
  "region": { "x": 100, "y": 100, "width": 800, "height": 600 }
}
```

- `output_dir`：本次保存目录，不传则用插件设置里的值。

- `region`：截取区域；不传则截全屏。走快捷键时这个参数由框选界面自动填。

返回值包含 `path`、`width`、`height`。

## 排查

- **按快捷键没反应**：到「设置 → 全局快捷键」看这一行是否标着「未生效」。多半是被别的软件（输入法、录屏工具）先占了系统热键，换一个组合即可。

- **提示权限被拒**：到「权限」页把 `screen:capture` 的记录删掉，下次调用会重新询问。

- **多显示器**：目前只截主屏幕。
